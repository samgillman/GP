# Column t tests, one-way ANOVA and pairwise comparisons

This unit makes the Column-table comparison workflow behave like Prism's: **Analyze → choose "t tests (and nonparametric tests)" or "One-way ANOVA (and nonparametric or mixed)" → parameters dialog → tabbed results → significance brackets on the graph**. It records what GP now does, what each choice is based on, and what remains open. Passing GP tests is **not** Prism equivalence; no Prism output was compared except the one saved paired-t case named below.

## What GP implements

| Area | GP behavior | Basis |
| --- | --- | --- |
| Analyze dialog | Column tables offer Descriptive statistics, "t tests (and nonparametric tests)" and "One-way ANOVA (and nonparametric or mixed)". The older single-test entries (`welch_t`, `paired_t`, `anova`) remain readable in saved workbooks and in the results-bar selector. | Guide family names; keeping old entries is a compatibility decision. |
| Parameters dialog | Opens before any calculation. t tests: **Experimental Design** (Unpaired/Paired; Gaussian yes/no; for unpaired Gaussian, equal SDs or Welch) and **Options** (two-/one-tailed, difference direction, α). One-way ANOVA adds **Multiple Comparisons** (none / every pair / each vs. a chosen control) and the sphericity choice for matched data. A t test with other than two selected data sets is refused in the dialog. | Guide page names and NIB option surface; layout, wording details and refusal are GP decisions. |
| Tests | Unpaired (Student), Welch, paired t; Mann–Whitney (exact when there are no ties and neither group exceeds 50 values, otherwise the tie-corrected normal approximation); Wilcoxon matched pairs (zero differences discarded); ordinary ANOVA with the Brown–Forsythe SD test and, when every column has at least five values, the corrected Bartlett test (audit P0241 guide statement); Brown–Forsythe and Welch ANOVA; repeated-measures ANOVA with Geisser–Greenhouse ε or sphericity assumed and a "Was the matching effective?" section; Kruskal–Wallis; Friedman. | Independent implementations checked against SciPy and closed forms. Exact/approximate thresholds and zero handling are GP choices. **Known guide differences:** the guide says Mann–Whitney P is exact even with ties when the smaller group has ≤100 values (audit P0199), Kruskal–Wallis P can be exact, and Friedman P is exact for small tables (audit P0256/P0257); GP uses the approximations described here. Pratt zero handling, lognormal tests and mixed effects are not offered. |
| Multiple comparisons | Ordinary: Tukey, Bonferroni, Šídák, Fisher LSD (all pairs) and Dunnett, Bonferroni, Šídák, Fisher LSD (vs control) on the pooled residual variance. Welch ANOVA: Games–Howell (all pairs only). Repeated measures: Tukey, Bonferroni, Šídák, Fisher LSD, each on that pair's differences. Nonparametric: Dunn's (tie-corrected, Bonferroni). Results report mean difference, 95% CI, "Below threshold?", summary and adjusted P. | Tukey uses GP's own studentized-range quadrature (agrees with SciPy to 2e-8); Dunnett uses the deterministic Dunnett (1955) integral because SciPy's CI search did not converge. Per-pair RM comparisons and the method lists per design are GP decisions; Holm–Šídák, Newman–Keuls, Dunnett T3, Tamhane T2 and FDR are not offered. |
| P-value display | "<0.0001", ">0.9999" or four decimals; summaries ns, *, **, ***, **** at 0.05/0.01/0.001/0.0001 from the full-precision P; "Significantly different (P < α)?" rows use the chosen α. Confidence intervals are always 95%. | Guide GraphPad style (audit P0400/P0404/P0406/P0407). The guide states ">0.9999" for Dunn's adjusted P (audit P0289); GP applies it to every GraphPad-style P, an implementation decision. APA/NEJM styles and α-linked CI level are not implemented. |
| Results sheet | One tab per results page (for example ANOVA results, ANOVA table, Multiple comparisons) plus Descriptive statistics, each a numbered grid with section rows. The analysis name follows the test ("Welch's t test of groups") and **Parameters…** reopens the dialog; OK changes that result in place and recalculates it. | Guide; Prism 11's closable tabs are not reproduced. |
| Persistence | Parameters are saved with the result, validated strictly on open, included in the recalculation key, and recorded in undo history. | GP workbook design (W002). |
| Pairwise brackets | **Add Pairwise Comparisons…** (Change menu and the Pairwise toolbar button) links a graph to one t test or one-way ANOVA result on the same table, with asterisks or P values and an option to hide non-significant pairs. Brackets are recomputed from the linked result, disappear while it is stale, follow it after data edits, persist across reload and are drawn identically in SVG/PNG/PDF export (shorter spans lowest, overlapping spans stacked). | Guide 4.6.1 describes the feature; bracket geometry, the dialog and the stale-hiding rule are GP decisions. Prism's first-click-adds-all, per-comparison selection, formatting controls and compact letter display are not implemented. |
| Website warm-up | The static (Pyodide) build starts loading its Python engine and the comparison module at first paint and shows "Loading analysis engine…" in the status bar, so the first analysis does not wait for the download. A failed warm-up is retried by the next real request. | Implementation decision for web delivery; Prism has no equivalent. |

## Verification

- `tests/test_column_tests.py` (28 tests): unpaired, Welch, one-tailed and reversed t against `scipy.stats.ttest_ind`; the saved Prism paired case; Mann–Whitney exact and tied approximations; Wilcoxon with zero differences; ANOVA, Brown–Forsythe, Bartlett and Tukey against SciPy; pooled Bonferroni/Šídák/Fisher; Dunnett against SciPy with 95% simultaneous coverage; Dunnett with one comparison equals the pooled t test; Welch/Brown–Forsythe ANOVA reduce to Welch's t for two groups and match SciPy's Welch ANOVA; Kruskal–Wallis and Dunn; repeated measures reduce to the paired t (F = t²) and ε matches the contrast formula; Friedman with ties; degenerate designs fail with explanations; API tables/comparisons and option validation; studentized range against SciPy; bracket layout; export with brackets and annotation validation; ">0.9999"/"<0.0001" display and the Bartlett five-value rule.
- `web/src/column-analysis.test.ts`, `web/src/workbook.test.ts` ("t test parameters persist with results…") and `web/src/plot-geometry.test.ts` ("pairwise brackets stack like the export…").
- `scripts/check_column_analysis.py` in Chromium against the packaged server build (2026-10-19, Chromium 1194): 10 scenarios passed with zero page errors — warm-up state; three-data-set refusal; unpaired t page vs SciPy; Parameters… → Welch in place; ANOVA tabs, F and Tukey adjusted P vs SciPy; one bracket per comparison; P-value labels with non-significant pairs hidden; brackets after a data edit vs a fresh SciPy Tukey; reload persistence; SVG export payload and file contain the same brackets. CI also runs it against the static build; that hosted result had not been observed when this was written, and the static build could not be assembled in this container (cdn.jsdelivr.net denied).
